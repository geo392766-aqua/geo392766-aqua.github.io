지도 × Claude API 실습

지도에서 아무 지점이나 클릭하세요.

1. Claude Code 설치

Node.js 18 이상이 필요합니다. 터미널에서 node -v로 확인하세요.

npm install -g @anthropic-ai/claude-code
claude --version

2. 환경 변수 설정

export ANTHROPIC_BASE_URL="https://api.synterolink.com"
export ANTHROPIC_AUTH_TOKEN="sk-f352e82d4f8e49c185d7b066bd5143579125affeb62459080643a47d562613db"
export CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
$env:ANTHROPIC_BASE_URL="https://api.synterolink.com"
$env:ANTHROPIC_AUTH_TOKEN="sk-f352e82d4f8e49c185d7b066bd5143579125affeb62459080643a47d562613db"
$env:CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC="1"
set ANTHROPIC_BASE_URL=https://api.synterolink.com
set ANTHROPIC_AUTH_TOKEN=sk-f352e82d4f8e49c185d7b066bd5143579125affeb62459080643a47d562613db
set CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1

등호(=) 앞뒤에 공백을 넣지 마세요.

3. 실행

cd 실습폴더
claude
이 폴더에 있는 파일 목록을 보여주고 각각 무슨 역할인지 설명해줘

4. 변수 설명

변수역할
ANTHROPIC_BASE_URL요청을 보낼 API 서버 주소
ANTHROPIC_AUTH_TOKEN인증 토큰
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC자동 업데이트 확인 등 부가 통신 끄기

5. 문제 해결

증상확인할 것
claude: command not found터미널을 새로 열거나 npm config get prefix 경로가 PATH에 있는지 확인
로그인 화면이 뜸환경 변수를 설정한 같은 창에서 실행했는지 확인
401 / 인증 오류토큰 복사 시 앞뒤 공백이나 따옴표 확인
변수 확인macOS·Linux: echo $ANTHROPIC_BASE_URL · PowerShell: echo $env:ANTHROPIC_BASE_URL · CMD: echo %ANTHROPIC_BASE_URL%
